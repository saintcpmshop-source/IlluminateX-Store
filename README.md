<h3 style="color: #38bdf8;">🌟 What is IlluminateX Store?</h3>

**IlluminateX Store** is a premium, high-end in-console App Store designed exclusively for CFW PlayStation 3s. It completely removes the need to use a PC or USB drive to install homebrew. 

Instead of searching the web and transferring files, you simply launch IlluminateX Store on your PS3. It fetches a curated list of the latest apps, lets you select what you want, and downloads the `.pkg` files directly to your console's HDD for immediate installation via the Package Manager.

<h3 style="color: #D4AF37;">⚡ Features</h3>
*   **📦 Direct GitHub Downloads:** Pulls the latest `.pkg` files straight from our official repositories.
*   **🎨 Custom UI:** A stunning, animated purple background with floating gold PlayStation icons.
*   **🚀 Auto-Installer:** Downloads directly to `/dev_hdd0/tmp/` for quick installation.
*   **🌐 Massive Library:** Includes essential tools like Apollo Save Tool, FTP Server, ArtemisPS3, and more, with new apps added constantly.

---

<h3 style="color: #38bdf8;">🚀 Why Use IlluminateX Custom Firmware?</h3>

While IlluminateX Store works perfectly on other CFWs (like Evilnat), it is specifically designed and optimized for the upcoming **IlluminateX Custom Firmware**. Here is why you should upgrade to IlluminateX CFW when it releases:

1. **Pre-Installed & Ready:** IlluminateX Store will come **pre-installed** on IlluminateX CFW. You won't even need to download it; it will be waiting on your XMB the moment you boot up.
2. **Silent Background Installation:** On IlluminateX CFW, the Store is deeply integrated. When you click download, it will automatically install the app in the background without you needing to navigate to the Package Manager manually.
3. **Custom Boot & UI:** IlluminateX CFW features the custom purple and gold coldboot, a custom XMB wave, and an exclusive purple/gold theme pre-applied.
4. **Zero-Setup Experience:** We are baking essential apps like multiMAN and webMAN MOD directly into the firmware, giving you a "plug-and-play" console experience right out of the box.
5. **Maximum Stability:** IlluminateX CFW is built from the ground up with the latest security patches and performance tweaks to ensure your console runs as smoothly as possible.

---

<h3 style="color: #D4AF37;">🛠️ How to Use the Store</h3>
1. Ensure your PS3 is connected to the internet.
2. Launch **IlluminateX Store** from the XMB.
3. Browse the list of available applications.
4. Select the app you want to download.
5. The `.pkg` will download to `/dev_hdd0/tmp/`.
6. Go to **Game > Package Manager** to install it!
